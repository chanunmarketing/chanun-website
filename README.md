# เว็บไซต์ CHANUN Aesthetic Wellness & Surgery

เว็บสองภาษา (ไทยเป็นหลัก อังกฤษอยู่ที่ `/en/`) แก้ข้อมูลและรูปได้เองผ่านหน้าแอดมิน ไม่ต้องแตะโค้ด

| ส่วน | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| ตัวเว็บ | Astro (สร้างเป็นหน้าเว็บสำเร็จรูป โหลดเร็ว) | ฟรี |
| ที่เก็บไฟล์ | GitHub | ฟรี |
| โฮสต์ | Cloudflare Pages | ฟรี |
| หน้าแอดมิน | Pages CMS (app.pagescms.org) | ฟรี |
| โดเมน .com | Cloudflare Registrar | ประมาณ 350–450 บาท/ปี |

## หน้าในเว็บ

- หน้าแรก: แนวคิดคลินิก, โปรแกรมเด่น, บทความล่าสุด, วิดีโอ YouTube, ที่อยู่และเวลาทำการ
- บริการและราคา: แยกตามหมวด แต่ละโปรแกรมมีหน้ารายละเอียด ตารางราคา เหมาะกับใคร ไม่ควรทำถ้า
- บทความ: บทความความรู้ ข่าวคลินิก วิดีโอ (กรองตามประเภทได้) ใส่แหล่งอ้างอิงท้ายบทความได้
- เกี่ยวกับเรา / แพทย์, ติดต่อ (แผนที่ Google Maps)
- ปุ่ม "นัดหมายทาง LINE" ทุกหน้า และแถบปุ่มลอยด้านล่างบนมือถือ

## วิธีแก้ข้อมูล (หลังเปิดเว็บแล้ว)

1. เข้า https://app.pagescms.org แล้ว Sign in with GitHub
2. เลือก repo `chanun-website`
3. เมนูซ้ายมือ:
   - **บริการและราคา** แก้ราคา เพิ่มโปรแกรมใหม่ เปลี่ยนรูป
   - **บทความ ข่าว และวิดีโอ** เขียนบทความ วางลิงก์ YouTube
   - **แพทย์**, **หน้าแรก**, **ข้อมูลคลินิก** (ที่อยู่ เวลา เบอร์ โซเชียล เลขใบอนุญาต)
4. กด **Save** เว็บจริงจะอัปเดตเองภายใน 1–2 นาที

เคล็ดลับ
- ราคา ใส่แค่ตัวเลข เช่น `4900` เว็บจะแสดงเป็น `4,900 บาท` ถ้าเว้นว่างจะขึ้นว่า "สอบถามราคา"
- ช่อง (EN) เว้นว่างได้ หน้าอังกฤษจะแสดงข้อความไทยแทน
- ซ่อนบริการหรือบทความชั่วคราว: ปิดสวิตช์ "แสดงบนเว็บ"
- รูปควรย่อให้กว้างไม่เกิน 2000px ก่อนอัปโหลด (เว็บจะเร็วขึ้น)
- วิดีโอ YouTube: วางลิงก์ได้ทุกแบบ (youtu.be, watch?v=, shorts)

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

1. **GitHub** สมัครที่ github.com แล้วสร้าง repo ชื่อ `chanun-website` (ตั้งเป็น Private ได้) แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นไป หรือให้ Claude push ให้
2. **Cloudflare Pages** สมัคร cloudflare.com → Workers & Pages → Create → Pages → Connect to Git → เลือก repo
   - Framework preset: `Astro`
   - Build command: `npm run build`
   - Build output directory: `dist`
   - จะได้เว็บที่ `ชื่อโปรเจกต์.pages.dev`
3. **Pages CMS** เข้า app.pagescms.org → Sign in with GitHub → Install GitHub App ให้ repo นี้
4. **โดเมน** (ถ้าต้องการ) Cloudflare → Domain Registration → Register Domain → แล้วไปที่โปรเจกต์ Pages → Custom domains → เพิ่มโดเมน จากนั้นแก้ "ที่อยู่เว็บ" ในหน้า **ข้อมูลคลินิก** ให้ตรง

## ก่อนเปิดใช้จริง ต้องแก้

- ราคาทุกโปรแกรม (ตอนนี้ขึ้น "สอบถามราคา")
- ที่อยู่เต็ม เวลาทำการ เลขใบอนุญาตสถานพยาบาล เลข ฆสพ. เลขใบประกอบวิชาชีพแพทย์
- รูปทั้งหมดในเว็บตอนนี้เป็นภาพตัวอย่าง ให้เปลี่ยนเป็นรูปคลินิกจริง
- ลิงก์ Facebook / TikTok / YouTube และวิดีโอ YouTube ที่จะโชว์หน้าแรก
- เนื้อหาโฆษณาบนเว็บไซต์สถานพยาบาลต้องได้รับอนุมัติจาก สบส. ก่อนเผยแพร่

## สำหรับนักพัฒนา

```
npm install
npm run dev      # http://localhost:4321
npm run build    # ได้ไฟล์ใน dist/
```

- เนื้อหา: `src/content/services`, `src/content/articles`, `src/content/doctors` (Markdown) และ `src/data/*.json`
- รูป: `public/uploads`
- หน้าตาเว็บ: `src/styles/global.css` (สีและฟอนต์อยู่ด้านบนไฟล์)
- ตั้งค่าหน้าแอดมิน: `.pages.yml`
